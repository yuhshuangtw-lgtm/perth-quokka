# Perth 2026 行程 🦘💗

西澳伯斯 10/24–10/31 遠端工作 × 自駕行程表（手機版單頁網站）。

- **即時狀態**：依伯斯時間顯示「現在 / 下一站 / 倒數」、工作時段提示、有車/無車
- **一鍵導航**：每個地點都有 Google Maps 導航（開車 / 步行 / 大眾運輸）
- 三個分頁：**行程**（即時狀態＋每日時間軸）、**羅島**（Rottnest 攻略）、**資訊**（住宿、旅伴、檢查表）
- **離線可用**：打開過一次後，沒訊號（Brand Hwy、羅特尼斯島）也能看行程
- 可勾選的檢查表（存在各自手機）

## 修改行程
只需編輯 `index.html` 裡 `DAYS`、`STAYS`、`CHECKLISTS` 這幾個資料區塊；Perth CBD 飯店確定後填入 `PERTH_HOTEL`。

## 測試某個時間點
網址後加 `?now=2026-10-27T13:10` 可模擬當下時間。

## 部署到 GitHub Pages
1. 在 GitHub 建立 repo，推上這個資料夾
2. Settings → Pages → Source 選 `main` 分支 / root
3. 網址為 `https://<帳號>.github.io/<repo>/`，手機打開後「加入主畫面」即可像 App 一樣使用
